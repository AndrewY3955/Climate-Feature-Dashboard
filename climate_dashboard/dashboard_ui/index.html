This view accounts for the environmental and technology features named in the assignment. It distinguishes source-backed observations from research context and features not collected; absence must never be interpreted as zero impact.

How to read the statuses: Source-reported means at least one reviewed publisher-reported observation exists. Partial means only part of the feature is represented or the geographic/organizational coverage is limited. Research context means the literature discusses the feature but no project observation measures it. Not collected means the current evidence set does not measure it or provide sufficient feature-specific evidence. The trusted dataset contains no estimated observations or derived analytical metrics. Standardized values that differ from source units are documented unit conversions with the original value retained; synthetic and adversarial copies are separate demonstrations.

Pipeline validation details

Power BI context-pack validation

Integrity is not accuracy. A matching hash compares file bytes with the referenced manifest. It does not authenticate the publisher, prove the source measurement, or prevent tampering when both files share write permissions.
SHA-256 is hashing, not encryption. SHA-256 creates a one-way digest to detect byte changes against a trusted reference. It does not encrypt, decrypt, or conceal file contents. This prototype does not implement application-level file encryption or encryption-key management.
