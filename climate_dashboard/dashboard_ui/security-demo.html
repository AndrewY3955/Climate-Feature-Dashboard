ATT&CK and adversarial scenarios

The three mapped techniques are T1078, T1565.001, and T1565.002. Multiple controlled variants exercise data alteration, omission, provenance loss, scope/unit changes, payload modification, and visualization filtering.

Like-for-like comparability audit

Direct comparison requires matching metric, unit, data year, geography, facility/organizational scope, lifecycle boundary, calculation method, and data status. Company identity may differ. Any mismatch is flagged; unlike metrics or units are not silently normalized.

Security boundaries and limitations

    SHA-256 is a one-way integrity hash, not encryption. AES-256-GCM is demonstrated as standalone file encryption and does not encrypt dashboard storage, GitHub Pages, or network traffic. MFA, role-based access, central audit logging, independent manifest custody, and production key management are not deployed.
